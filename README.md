## 🏠 Mi Homelab

> Mi laboratorio personal: donde las cosas se rompen a propósito para aprender a arreglarlas.

```
┌─────────────────────────────────────────────────────┐
│  🖧  PROXMOX VE (hipervisor)                        │
│  ├── 📦 LXC · Servicios ligeros y pruebas           │
│  ├── 🎬 VM  · Servidor multimedia (Jellyfin + arr)  │
│  ├── 🌐 VM  · Reverse proxy + certificados SSL      │
│  └── 🧪 VM  · Sandbox — aquí se rompe todo primero  │
│                                                     │
│  🔒 Acceso remoto: WireGuard VPN + SSH con claves   │
│  💾 Backups automatizados y verificados             │
│  📊 Todo documentado y reproducible                 │
└─────────────────────────────────────────────────────┘
```

**Lo que he aprendido montándolo:** virtualización real (no la de los apuntes), redes entre VMs y VLANs, gestión de almacenamiento, automatización de despliegues, y sobre todo: *a leer logs antes de preguntar*.
