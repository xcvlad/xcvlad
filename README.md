## Homelab

Mi laboratorio personal sobre **Proxmox VE**, funcionando 24/7:

| Servicio | Función |
|---|---|
| **Stack *arr completo** | Automatización total de biblioteca multimedia |
| **Jellyfin** | Servidor multimedia para toda la red |
| **AdGuard Home** | DNS con bloqueo de publicidad a nivel de red |
| **Tailscale** | Acceso remoto seguro desde cualquier sitio, sin abrir puertos |
| **Raspberry Pi** | Servicios ligeros y experimentos |
| **Sandbox** | VMs desechables — aquí se rompe todo primero |

Lo que me ha enseñado: virtualización real, redes entre VMs, gestión de almacenamiento
y RAID, resolución de problemas leyendo logs, y que un buen backup vale más que mil tutoriales.
